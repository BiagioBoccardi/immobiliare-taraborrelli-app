# Logo Immobiliare Taraborrelli

| File | Uso |
|---|---|
| `logo-original.jpg` | Originale fornito dall'agenzia |
| `logo.png` | Logo blu su sfondo trasparente, per sfondi chiari |
| `logo-white.png` | Logo bianco su sfondo trasparente, per sfondi blu |
| `icon-64.png`, `icon-192.png`, `icon-512.png` | Solo il simbolo, per favicon e icone dell'app |

Il blu del marchio misurato sull'originale è `#0361A4` (`colors.brandBlue` in `src/index.ts`).

## Carattere dei titoli

`fonts/eb-garamond-latin-wght-normal.woff2`: EB Garamond (peso variabile, caratteri latini), usato per
i titoli perché vicino alle lettere del logo. Licenza SIL Open Font License 1.1 (`fonts/EB-Garamond-OFL.txt`).
Il file è incluso nel progetto e non viene caricato da servizi esterni.
